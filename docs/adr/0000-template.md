# ADR-0000 — Template

**Status:** template
**Date:** YYYY-MM-DD
**Supersedes / superseded by:** —

## Context

What forced a decision. Include the measurement or the failure that prompted it, not just the
preference.

## Decision

What we are doing, in the imperative.

## Consequences

What becomes easier, what becomes harder, and **which already-reported results must be re-run**.
A protocol change with no re-run list is an incomplete ADR.

## Alternatives considered

Each with the reason it lost. "We did not think of it" is an acceptable entry; silence is not.

## Evidence

The experiment, the config hash, the run id, or the citation. If the decision was made without
evidence, say so explicitly and record what evidence would revise it.
